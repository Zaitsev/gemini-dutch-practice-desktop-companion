Bootstrap wails go-lang application with Firebase backend integration. This document outlines the initial requirements and architecture for the desktop companion application, ensuring secure and efficient communication with the Firebase backend for AI model interactions and data management.

- google login (as in gemini-dutch-practice) with firebase auth
- periodic pop-ups with flash-cards  (data from firebase user's dictionary)
- use api defined in firebase-backend for all interactions with firebase (e.g. get flashcards, update flashcards, etc.)
- reuse GUI components from gemini-dutch-practice where possible, keep the UI simple but as close by design as possible to the web app (e.g. same colors, fonts, etc.)
